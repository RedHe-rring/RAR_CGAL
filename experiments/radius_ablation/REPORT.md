# Radius Guard 机制分离与消融实验

本次完成了三个新模式、初始场诊断、编译与测试，以及指定的三模型 × 五模式实验。15/15 组运行成功，无参数替换，无输入替代。**Wine 的大幅减面主要来自 Recovery；Shark 的误差与质量改善主要来自 Cap；Camel 的全局变化较小，但 Cap 区域的局部变化不能忽略。** 这些结论针对本次固定输入、参数和采样协议，不等于所有模型上的普遍保证。

## 2. 固定实验协议与指标

| 输入（仓库相对路径） | epsilon | 输入 V/F |
|---|---:|---:|
| `data/wine_glass24.ply` | 0.0214378565 | 1489 / 2974 |
| `data/camel2.ply` | 0.001 | 8462 / 16912 |
| `data/shark13.ply` | 0.003106642746 | 9005 / 17998 |

全部固定 `--min-edge 0.001 --max-edge 0.5 --iterations 5 --relax-steps 3 --no-preserve-features`，Projection 开启，Chen 关闭。每组独立读取原始输入；完整命令、退出码、标准输出和错误日志均保留。程序计时包括场构造与 remeshing，不含独立诊断及输入/输出 I/O；另存完整 wall time。时间是单次观测，不是重复测量的性能基准。

几何参考为上述输入 PLY，未找到或假定额外解析真值。每个方向固定 80,000 个按面积均匀采样的表面点；参考种子 731，输出种子 343，同一模型的五组共享同一参考样本。VTK `vtkStaticCellLocator` 查询点到三角形表面的最近距离，不是顶点到顶点距离。

- **CD²** = `(mean(d_ref→out²) + mean(d_out→ref²))/2`，单位为输入坐标单位的平方；另存未平方的双向平均距离。
- P99 为 160,000 个双向距离合并后的第 99 百分位；另存各方向 P99。Max 为最大采样距离，**不是精确 Hausdorff**。
- MinAngle P05 单位为度；Tri.Q=`4√3 A/(a²+b²+c²)`；AR=`√3·max(a,b,c)²/(4A)`，等边三角形两者为 1。分位数按输出面数加权。
- W/C 为 Watertight/面邻接连通分量数。区域面积比例全部按输入顶点的三分之一关联面面积加权。
- 相对体积只在输入/输出均闭合、无自交且通过 CGAL `does_bound_a_volume`、正有向体积检查时计算。

**有效性结果：全部输出虽闭合，CGAL 均检出自交。Wine 输入通过有效体积检查，Camel/Shark 输入已有自交。18 个被检查网格均无退化三角形，因此这里的失败确为自交检测结果。所有相对体积变化标为 N/A。** CSV 的 `vol` 只保留代数有向体积，不能当作实体体积。该发现不阻止比较到输入三角形集合的表面距离，但限制了实体几何结论。详见 [体积检查记录](volume_validation.json)。

## 5. 适配器控制、局部对应及结论边界

**原生 CGAL 与 PropertyMapSizingField 在本次三个模型上没有可见差异：不仅计数和指标一致，输出文件 SHA-256 也完全相同。** 当前适配器与本机 CGAL 的长短边判据、分裂中点及新顶点邻居均值更新相符；不能把本次 Radius 效果归因于适配器差异。这是对本次版本和输入的验证，不是所有未来版本/边界配置的等价性证明。

区域密度算法：给初始每个顶点定义三个互斥标签，在每个输入三角形内部按重心坐标线性插值标签权重。输入区域面积严格等于对应 `vertex_area` 之和。将每个输出面重心投影到输入最近三角形，在最近点插值得到三个区域权重；按权重分摊一个输出面，得到区域“等效面数”，再除以固定输入区域面积。三个区域等效面数之和等于总面数。局部误差则使用原始参考采样点上的同一权重，计算参考→输出距离的加权均值与 P99。

这种最近面对应不包含拓扑、法线或部件约束。薄壁近邻、相交面或杯口附近可能跨层匹配；输出面重心也只是对整面区域归属的单点近似。Full 的最近面反向法线比例约为 Wine **0.771%**、Camel **0.222%**、Shark **1.443%**，并非零；该指标也不能排除法线同向的错配。故局部数值是空间证据，不应解释为逐个输出面的严格因果标签。完整区域指标见 [local_density.csv](local_density.csv)。

得到支持的事实与机制解释：

1. 原始 CGAL 的负尺寸平方在 `t>2` 被裁剪到 min-edge；当 `1/kappa>min-edge` 时，Guard 能恢复更大尺寸。Wine 的初始场、元素数代理和实际局部减密共同支持 H1。
2. Shark 的 Cap-only 复现并超过 Full 的主要误差/质量改善，且 Cap 区域同步增密、误差下降，支持 H2；同时有面数成本。
3. Camel 的覆盖面积小且没有高端恢复区，解释了较小的全局变化；局部 Cap 效果仍明显。

被本次结果否定的泛化说法：仅用 `t>0.183` 面积就能预测实际机制；Recovery 必然改善误差；Full 必然改善所有质量/极端误差指标；闭合输出就有有效实体体积；Cap 与 Recovery 的最终面数/误差贡献可直接相加。

尚未验证：跨 epsilon、min/max-edge 与模型的普适性，多种子误差稳健性、固定面数下的公平性、空间映射的真实层间对应，以及自交产生的具体操作和位置。这里没有为了验证假设调整任何实验参数，也没有修复或清洗输入。

## 6. Radius Guard 后续可改进的方向

- 将 0.183 的舍入过渡与真正的高端 Recovery 分别报告，评估精确低端交点或连续过渡能否消除微小反向跳变；本次保留旧公式，未实施改动。
- 保留实际尺寸方向及 min/max 裁剪诊断。Shark 说明高 `t` 不等于有效 Recovery，整体代理量也可能掩盖增密/减密的抵消。
- 对曲率噪声、尺寸渐变、薄结构及投影对应单独开展实验。Wine 减面很强，但局部误差及最大采样距离仍有代价；本次未启用 Chen，不能据此推断 Chen 是否会解决问题。
- 把自交和实体有效性列为后续质量目标。本次 Radius 的尺寸控制不能保证无自交；Camel/Shark 还需区分输入已有问题与新产生问题。
- 补充多个采样种子和固定面数比较，避免把离散局部操作传播或微小采样差异解释为稳定优势。
